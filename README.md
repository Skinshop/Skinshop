# SKINSHOP — sitio web

## Estructura
- `index.html` — todo el contenido y las secciones del sitio.
- `css/style.css` — estilos (colores, tipografía, layout, responsive).
- `js/data/config.js` — **editar acá** el nombre, slogan, WhatsApp, ubicación, servicios y marcas.
- `js/data/spareParts.js` — catálogo de repuestos (generado desde la lista de precios del proveedor). No editar a mano: pedile a Claude que lo regenere si cambian los precios.
- `js/app.js` — lógica del sitio (menú, WhatsApp, sistema de presupuesto, catálogo, mapa).

## Cómo ver el sitio
Abrí `index.html` en el navegador (doble clic), o subí la carpeta completa a cualquier hosting estático (Netlify, GitHub Pages, Hostinger, etc.).
